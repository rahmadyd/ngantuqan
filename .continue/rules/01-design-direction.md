
## Layout Preservation Policy

This project requires a VISUAL REFRESH,
not a complete layout redesign.

The existing website structure is intentional
and must be preserved.

### Strict Layout Constraints

1. Preserve the existing section order.
2. Preserve the existing page structure.
3. Preserve existing content placement.
4. Preserve existing grid structures.
5. Preserve existing component hierarchy.
6. Preserve existing spacing and layout relationships
   unless a specific visual issue requires adjustment.
7. Do not introduce new sections.
8. Do not remove existing sections.
9. Do not rearrange existing content.
10. Do not rebuild existing pages from scratch.

### Hero Section Exception

The homepage hero is the ONLY section authorized
for significant layout and composition changes.

The hero may receive:
- New composition.
- New visual hierarchy.
- New illustration placement.
- New background treatment.
- New typography arrangement.
- New decorative elements.

However, preserve its existing content,
calls to action, and functionality.

### Other Sections

All other sections must retain their
existing layout and composition.

Only visual styling changes are permitted:
- Colors.
- Typography.
- Backgrounds.
- Borders.
- Shadows.
- Image treatments.
- Decorative elements.
- Icon styling.
- Hover effects.
- Subtle animations.

Do not change structural layout properties
without identifying a specific problem
and obtaining approval.

### Responsive Preservation

Preserve existing responsive behavior.

Do not introduce horizontal overflow,
unexpected stacking, broken grids,
or altered mobile navigation.

### Approval Requirement

If a visual improvement requires changing
the structure of a non-hero section,
explain the reason and request approval first.
